# 大学生在线选课系统运行说明

本文档提供了如何快速运行大学生在线选课系统的详细说明。

## 系统要求

在运行系统前，请确保您的计算机已安装以下软件：

- JDK 8 或更高版本
- Python（用于启动简易HTTP服务器）

## 运行步骤

### 方法一：使用一键运行脚本（推荐）

#### Linux/macOS用户

1. 打开终端，进入项目根目录
2. 执行以下命令给脚本添加执行权限：
   ```
   chmod +x run.sh
   ```
3. 运行脚本：
   ```
   ./run.sh
   ```
4. 脚本会自动编译Java代码并启动HTTP服务器
5. 在浏览器中访问：http://localhost:8000

#### Windows用户

1. 打开命令提示符或PowerShell，进入项目根目录
2. 运行批处理脚本：
   ```
   run.bat
   ```
3. 脚本会自动编译Java代码并启动HTTP服务器
4. 在浏览器中访问：http://localhost:8000

### 方法二：手动运行

如果您不想使用一键运行脚本，也可以按照以下步骤手动运行系统：

1. 编译Java代码：
   ```
   mkdir -p classes
   javac -d classes $(find src -name "*.java")
   ```

2. 配置Web应用：
   ```
   mkdir -p web/WEB-INF/classes
   cp -r classes/* web/WEB-INF/classes/
   ```

3. 启动HTTP服务器：
   ```
   cd web
   python -m http.server 8000
   ```

4. 在浏览器中访问：http://localhost:8000

## 注意事项

请确保在运行系统前，已经正确配置了数据库。本脚本不会自动创建或初始化数据库，需要您手动执行以下操作：

1. 创建名为"university"的数据库
2. 导入项目根目录下的database.sql脚本
3. 确保src/util/DBUtil.java中的数据库连接配置正确

## 常见问题

### 编译错误
- 确保JDK已正确安装
- 检查compile_errors.log文件了解详细信息

### 网页无法访问
- 确保HTTP服务器正在运行
- 检查端口8000是否被占用，如果被占用，可以修改脚本中的端口号

### 其他问题
如果遇到其他问题，请参考项目文档或联系开发人员获取帮助。

## 关闭系统

运行完毕后，可以按 Ctrl+C 停止HTTP服务器。
